병현이의 긍정카드 100장 · GitHub 업로드 안내

이 ZIP은 images 100장과 assets 아이콘 3개를 포함한 전체 웹앱입니다.
ZIP 파일 자체를 GitHub에 올리지 말고 반드시 먼저 압축을 풀어 주세요.

현재 저장소의 이미지 오류를 고치는 순서
1. 압축을 푼 위치에서 images 폴더를 찾습니다.
2. GitHub 저장소 최상위(index.html이 보이는 곳)에서 Add file → Upload files를 엽니다.
3. images 폴더 자체를 업로드 화면에 끌어다 놓습니다. 폴더 안의 이미지 파일만 선택해 올리면 경로가 달라집니다.
4. 파일 목록에 images/001.webp 같은 경로가 표시되는지 확인하고 Commit changes를 누릅니다.
5. assets 폴더도 같은 방식으로 따로 올리고 Commit changes를 누릅니다.
6. 배포가 완료되면 사이트를 새로고침합니다.

루트의 app.js와 sw.js도 이번 ZIP의 파일로 교체해 주세요.
이번 sw.js는 캐시 버전이 변경되었습니다.

정상 위치
index.html
app.js
style.css
cards.json
manifest.webmanifest
sw.js
images/001.webp ~ images/100.webp
assets/icon-192.png
assets/icon-512.png
assets/icon.svg

한 번에 올리기 어려우면 images 폴더와 assets 폴더를 나눠서 올려 주세요.
images 폴더 안의 파일을 50개씩 나눠 올릴 경우에는 GitHub의 images 폴더 안에서 업로드해야 합니다.

중요
- PNG 원본 이미지 ZIP 대신 이번 웹앱 ZIP 안의 .webp 이미지를 사용합니다.
- images 폴더 이름과 001.webp 같은 파일명을 바꾸지 않습니다.
- 압축 파일의 이름으로 된 상위 폴더를 통째로 올려서 index.html이 한 단계 안으로 들어가지 않게 합니다.
- 기존 파일을 삭제할 필요는 없습니다. 같은 위치에 올리면 교체됩니다.

문구 100장과 음악 링크는 기존 제작본을 유지했습니다.
음악의 실제 재생·전곡 청취는 아직 미검증입니다.
이 파일을 다시 만든 작업은 원격 GitHub 저장소를 자동 수정하지 않습니다.

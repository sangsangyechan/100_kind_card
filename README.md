# 병현이의 긍정카드 · 100장

입체 뜨개질 흰 진돗개가 건네는 모바일 긍정카드 100장입니다. 아이보리 테마, 첫 접속 랜덤, 바로 같은 카드가 나오지 않는 무제한 랜덤, 페이드 전환, 이름 변경, 선물 링크, 주제별 목록, 카드별 외부 YouTube 음악 버튼을 제공합니다.

## 들어 있는 것

- `index.html`, `style.css`, `app.js`: 웹앱
- `cards.json`: 제목·본문·그림·카드별 음악 100개
- `images/001.webp`~`100.webp`: 개별 고해상도 이미지(원본과 같은 픽셀 크기, WebP 품질94)
- `assets/`: 홈 화면 아이콘
- `manifest.webmanifest`, `sw.js`: 설치 및 기본 화면/최근 본 이미지 캐시
- `music_verification.json`: 공식 영상 메타데이터 확인 근거와 한계
- `verification_report.json`: 파일 및 기능 점검 기록
- `.github/workflows/pages.yml`: GitHub Pages 자동 배포 설정
- `deploy-github.sh`: GitHub CLI를 이용하는 배포 스크립트

원본 PNG 100장은 별도 `byeonghyeon_positive_cards_100_original_images.zip`에 있습니다. PNG100개는 각각 생성한 원본이며 합본 분리나 확대 이미지가 아닙니다. 대부분 1086×1448이고 일부는1189×1323입니다.

## 문구

001~025 제목·본문은 승인 ZIP과 문자 단위로 동일합니다. 026~100은 새로 작성한 제목1문장·본문3문장입니다. 이름 변경은 화면과 선물 링크에만 적용하며 카드 기록·개인 이름을 서버나 로컬스토리지에 저장하지 않습니다.

## 음악 확인 범위

공식 아티스트/Topic 채널 및 배급사 설명, Inst./Instrumental 발매 표기 또는 공식 피아노·관현악 연주 음반 정보를 근거로100곡을 선별했습니다. 곡마다 다른 공식 개별 YouTube watch URL이며 검색 링크는 없습니다. 원래 음악 후보 중004·009·010은 유지했고 나머지는 확인 가능한 곡으로 바꿨습니다.

직접 YouTube 재생 접근이 제한되어 실제 재생·전곡 청취·가사/허밍/코러스의 완전 부재는 검증하지 못했습니다. 따라서 '100곡 무가사 청취 검증 완료'로 볼 수 없습니다. 감정 배정은 문구 주제와 알려진 곡 분위기·제목에 따른 것으로 전곡 청취를 통한 최종 적합성 확인은 남아 있습니다. 근거와 상태는 각 카드와 music_verification.json에 기록했습니다. 일부 곡은 한국 드라마 OST 외의 피아노·영화·고전 연주곡입니다.

음원 파일은 포함하거나 재배포하지 않으며 YouTube 외부 링크만 제공합니다.

## 실행 및 홈 화면 설치

ZIP을 풀고 GitHub Pages 같은 HTTPS 정적 호스팅에서 엽니다. 파일을 더블클릭한 file:// 주소에서는 브라우저 보안 정책상 cards.json 읽기가 차단될 수 있습니다. 개발 환경에서는 `python3 -m http.server 8000` 후 http://localhost:8000 을 엽니다.

안드로이드 Chrome에서는 메뉴의 '홈 화면에 추가' 또는 '앱 설치'를 사용합니다. 브라우저가 설치 이벤트를 제공하면 앱 아래에도 설치 버튼이 표시됩니다. 설치 동작은 실제 기기에서 최종 확인이 필요합니다.

기본 화면과 최근 본 최대30장의 그림을 브라우저 캐시에 저장합니다. 처음부터100장을 모두 내려받지는 않습니다. 외부 음악과 처음 보는 그림은 인터넷이 필요합니다. 외부 글꼴을 불러오지 못하면 기기 기본 글꼴을 사용합니다.

## 선물 링크

이름을 바꾸고 '이 마음 선물하기'를 누르면 현재 카드 번호와 이름이 포함된 링크를 공유하거나 복사할 수 있습니다. 링크를 받은 사람은 해당 카드부터 시작합니다. 이름과 카드번호는 URL에 포함됩니다.

## GitHub Pages 배포

웹앱 ZIP의 파일들을 저장소 최상위에 올리고 Settings → Pages → Source를 GitHub Actions로 선택합니다. main 브랜치에 파일을 올리거나 Actions에서 Publish positive cards를 실행합니다. .github 폴더와 워크플로 파일도 포함해야 합니다. .nojekyll도 함께 제공합니다. 명령줄 사용자는 새 저장소에 한해 `bash deploy-github.sh`를 사용할 수 있습니다. 기존 저장소에는 자동으로 덮어쓰지 않습니다.

이번 실행에서 GitHub 연결 상태는 확인됐지만 저장소 조회·생성·업로드 도구가 노출되지 않았고 CLI도 인증 상태가 아니어서 원격 저장소 생성이나 실제 배포는 하지 못했습니다. 공개 URL은 아직 없습니다.
